# sapintegrationsuite_integration_adapter_deployment (Resource)

Deploys a custom adapter imported with
[`sapintegrationsuite_integration_adapter`](integration_adapter.md). SAP requires the adapter to
be deployed before any integration flow that uses it; the provider cannot see that dependency
in the flow's content, so declare it with `depends_on` on the flow deployment.

**Status:** partial. SAP documents the deploy request. Status polling and undeploy use the
runtime artifact API that all other deployments use; that adapters appear there was inferred,
not documented.

## Prerequisites

- The adapter on the tenant.
- An OAuth client with `WorkspaceArtifactsDeploy` and `MonitoringDataRead`.

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Deploys the adapter (SAP's deploy takes no version) and polls the runtime status until `STARTED` or `ERROR`, or `timeouts.create` (default 10 minutes) elapses. |
| Read | Reads the runtime artifact; an undeployed adapter drops out of state. |
| Update | None. |
| Replacement | Changing `adapter_id` or `runtime_location_id` undeploys and deploys anew. To redeploy after a new import of the same adapter, use `terraform apply -replace` on this resource. |
| Delete | Sends the undeploy request (bounded by `timeouts.delete`, default 10 minutes). |

A deploy that does not reach `STARTED` in time, or ends in `ERROR`, stays in state with SAP's
last status and is marked tainted, so the next apply deploys again.

## Example Usage

```terraform
resource "sapintegrationsuite_integration_adapter_deployment" "sftp_extension" {
  adapter_id = sapintegrationsuite_integration_adapter.sftp_extension.id
}

# SAP documents that a custom adapter must be deployed before an
# integration flow consuming it is deployed. This provider does not infer
# that dependency automatically from integration flow content - declare it
# explicitly.
resource "sapintegrationsuite_integration_flow_deployment" "orders" {
  package_id   = sapintegrationsuite_integration_package.utilities.id
  flow_id      = sapintegrationsuite_integration_flow.orders.flow_id
  flow_version = sapintegrationsuite_integration_flow.orders.version

  depends_on = [
    sapintegrationsuite_integration_adapter_deployment.sftp_extension,
  ]
}
```

## Import

```shell
terraform import sapintegrationsuite_integration_adapter_deployment.sftp_extension custom-sftp-extension
```

The ID is the adapter ID.

## Limitations

- **SAP:** no version parameter on deploy; whatever design-time adapter exists is deployed.
- **Provider:** whether adapters need longer than content to appear in the runtime status has
  not been measured. Edge Integration Cell targeting is not supported.
