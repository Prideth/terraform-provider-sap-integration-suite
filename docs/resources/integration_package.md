# sapintegrationsuite_integration_package (Resource)

An integration package groups design-time artifacts: integration flows, message mappings,
value mappings, script collections and custom adapters. Every artifact resource of this
provider names its package in `package_id`, so the package is usually the first resource in a
configuration.

**Status:** supported. Backed by `IntegrationPackages` of the Integration Content API.

## Prerequisites

- Cloud Integration activated in the SAP Integration Suite subscription.
- An OAuth client with `WorkspacePackagesEdit` (`WorkspacePackagesRead` for the data source).

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Creates a customer package. SAP requires `short_text`. |
| Read | Reads name, texts and version. SAP stores the description as HTML and wraps plain text in `<p>...</p>`; the provider removes that wrapper, so a plain description does not show as drift. |
| Update | `name`, `short_text` and `description` change in place with a `PUT`. The provider reads the package first and sends its version, vendor and tag fields back unchanged, because a `PUT` without them resets them. |
| Replacement | Changing `id` creates a new package. SAP identifies a package by its ID and offers no rename. |
| Delete | Deletes the package. Artifacts managed in the same configuration reference the package, so Terraform deletes them first. |

## Example Usage

```terraform
resource "sapintegrationsuite_integration_package" "utilities" {
  id          = "UTILITIES"
  name        = "Utilities Integration"
  short_text  = "Utilities integration content"
  description = "Integration content for the utilities line of business"
}
```

## Schema

### Required

- `id` (String) The package's technical ID. Immutable: changing it replaces the package.
- `name` (String) The package's display name.
- `short_text` (String) The package's short description, shown in the package list. Required by SAP: a create without it fails with "Property 'ShortText' cannot be empty".

### Optional

- `description` (String) A free-text description of the package. SAP stores it as HTML and wraps plain text in a paragraph (<p>...</p>); the provider removes that wrapper when reading, so a plain-text value round-trips unchanged.

### Read-Only

- `version` (String) The package version reported by SAP.

## Import

```shell
terraform import sapintegrationsuite_integration_package.utilities UTILITIES
```

Everything is recovered from SAP.

## Limitations

- SAP-delivered packages (from the Business Accelerator Hub) are read-only by SAP's design;
  manage only packages you create.
- The package's version, vendor and tag values are kept as SAP holds them; this resource
  cannot set them.
