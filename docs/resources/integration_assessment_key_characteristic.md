# sapintegrationsuite_integration_assessment_key_characteristic (Resource)

A key characteristic is a criterion Integration Assessment rates technologies on, for example
*Connectors* or *Data transformation*. In a questionnaire it becomes a question whose answers are
its values. Its type decides the question: *Single* is answered with yes or no, *Multi* with one
or more of the values.

**Status:** experimental. Needs `enable_experimental = true` in the provider block. SAP's Entities API
specification on the Business Accelerator Hub documents creating, updating and deleting this
entity, but the resource has not passed an acceptance test on a tenant yet, so its behavior or
schema may still change.

## Prerequisites

- `enable_experimental = true` and the `integration_assessment` provider block, with the service
  key of an *Integration Assessment APIs* service instance (plan `default`). The Cloud Integration
  credentials do not work for this API.
- An Integration Assessment subscription in the subaccount.
- A group: [`sapintegrationsuite_integration_assessment_key_characteristic_group`](integration_assessment_key_characteristic_group.md) or one of SAP's groups from the [data source](../data-sources/integration_assessment_key_characteristic_group.md).

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Creates the key characteristic in the group given in `key_characteristic_group_id`. |
| Read | Reads the name, the description, the type and the group. |
| Update | `name` and `description` change in place (PATCH). Removing `description` clears it. |
| Replacement | Changing `key_characteristic_group_id` or `is_single` creates a new key characteristic, and with it new values. The specification's update body has no group, and SAP refuses to update the type (400 V101), although the specification lists it. |
| Delete | Deletes the key characteristic. Values that refer to it are deleted first, because Terraform orders by the reference. |

## Example Usage

```terraform
# Experimental: needs enable_experimental = true and provider.integration_assessment.
resource "sapintegrationsuite_integration_assessment_key_characteristic" "data_residency" {
  name                        = "Data residency"
  description                 = "Where the integration technology processes and stores message data"
  key_characteristic_group_id = sapintegrationsuite_integration_assessment_key_characteristic_group.compliance.id
}

# A Single key characteristic: a question answered with yes or no.
resource "sapintegrationsuite_integration_assessment_key_characteristic" "audit_log" {
  name                        = "Audit log"
  is_single                   = true
  key_characteristic_group_id = sapintegrationsuite_integration_assessment_key_characteristic_group.compliance.id
}
```

## Schema

### Required

- `key_characteristic_group_id` (String) Id of the group, from sapintegrationsuite_integration_assessment_key_characteristic_group (resource or data source). Changing it creates a new key characteristic: the specification's update body has no group.
- `name` (String) The key characteristic's name. Changes in place.

### Optional

- `description` (String) A description of the key characteristic. Changes in place; removing it clears it.
- `is_single` (Boolean) The type the UI shows: true for Single, a question answered with yes or no; false (the default) for Multi, a question with several answers. Changing it creates a new key characteristic: SAP refuses to update the type.

### Read-Only

- `id` (String) Id the service assigns to the key characteristic on create (a UUID). Use it to link other objects and to import.

## Limitations

- **SAP:** a *Single* key characteristic has exactly one value; SAP refuses a second (400 V170).
- **Not yet tested on a tenant:** whether SAP accepts groups of its own next to its delivered
  ones, what a delete does while values or technology ratings still refer to an entry.
- **Provider:** only entries the configuration creates are managed. SAP's delivered entries are
  looked up with the data sources and never changed.
