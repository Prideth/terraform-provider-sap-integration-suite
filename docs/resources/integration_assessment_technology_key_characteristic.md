# sapintegrationsuite_integration_assessment_technology_key_characteristic (Resource)

A technology key characteristic rates a technology on one value of a key characteristic of
SAP's Integration Solution Advisory Methodology, with a recommendation degree that says how
strongly the technology meets it. The assessment compares these ratings when it recommends
technologies for an interface.

**Status:** unofficial. Needs `enable_unofficial = true` in the provider block. SAP documents the
Integration Assessment Entities API and this entity, but the field-level specification on the
Business Accelerator Hub needs an SAP login. The requests follow the service's `$metadata` and
were verified on a tenant in September 2026; SAP may change them without notice.

## Prerequisites

- `enable_unofficial = true` and the `integration_assessment` provider block, with the service key
  of an *Integration Assessment APIs* service instance (plan `default`). The Cloud Integration
  credentials do not work for this API.
- An Integration Assessment subscription in the subaccount.
- The technology's Id, from [`sapintegrationsuite_integration_assessment_technology`](integration_assessment_technology.md) (resource or data source).
- The value's Id from [`sapintegrationsuite_integration_assessment_key_characteristic_value`](../data-sources/integration_assessment_key_characteristic_value.md) and the degree's Id from [`sapintegrationsuite_integration_assessment_recommendation_degree`](../data-sources/integration_assessment_recommendation_degree.md).

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Creates the rating, linked to the technology, the value and the degree, with the description if set. |
| Read | Reads the three links and the description. |
| Update | None: the service has no update for this entity. |
| Replacement | Any change deletes the entry and creates a new one. |
| Delete | Deletes the entry. The technology and the taxonomy entries stay. |

## Example Usage

```terraform
# Unofficial: needs enable_unofficial = true and provider.integration_assessment.
# Every change creates a new rating; the service refuses to update one.
resource "sapintegrationsuite_integration_assessment_technology_key_characteristic" "acme_esb" {
  technology_id               = sapintegrationsuite_integration_assessment_technology.acme_esb.id
  key_characteristic_value_id = data.sapintegrationsuite_integration_assessment_key_characteristic_value.selected.id
  recommendation_degree_id    = data.sapintegrationsuite_integration_assessment_recommendation_degree.selected.id
  description                 = "Rated by the integration architecture board"
}
```
