# sapintegrationsuite_secure_parameter (Resource)

A secure parameter stores one confidential value, such as an API key, under a name that
custom adapters and scripts use as an alias. The value is write-only: Terraform sends it to SAP
but never stores it, and SAP returns it as null.

**Status:** unofficial. Needs `enable_unofficial = true` in the provider block. SAP Help
describes secure parameters only in the Monitor UI, and `SecureParameters` is not among the API
resources SAP lists. The entity set comes from the Security Content service's `$metadata`;
create, read, update and delete were verified on a tenant in September 2026. SAP can change it
without notice.

## Prerequisites

- `enable_unofficial = true`.
- An OAuth client with `CredentialsEdit`.
- Terraform 1.11 or later for `secure_param_wo`.

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Stops if a parameter of that name exists (SAP does not document what a create over it does), then creates and deploys it. |
| Read | Reads description, status and who deployed it when. The value is never returned. |
| Update | Any change redeploys the parameter with `PUT`, sending the configured value, because the update replaces the artifact. |
| Replacement | Changing `id` creates a new parameter. |
| Delete | Deletes the parameter. |

**Changing the value.** Put the new value into `secure_param_wo` and change
`secure_param_wo_version`.

## Example Usage

```terraform
# Unofficial: needs enable_unofficial = true in the provider block. The API
# behind it is known only from the service's $metadata, not from SAP's
# documentation.
variable "custom_adapter_api_key" {
  type      = string
  sensitive = true
}

# Integration flows and scripts reference the value through the alias
# CUSTOM_ADAPTER_API_KEY.
resource "sapintegrationsuite_secure_parameter" "custom_adapter_api_key" {
  id          = "CUSTOM_ADAPTER_API_KEY"
  description = "API key of the custom adapter's backend"

  # secure_param_wo is write-only: Terraform never stores it in plan or state.
  # Change secure_param_wo_version whenever the value itself changes, so
  # Terraform redeploys the artifact with the new value.
  secure_param_wo         = var.custom_adapter_api_key
  secure_param_wo_version = "1"
}
```

## Schema

### Required

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `id` (String) The artifact's name, which integration flows use as the alias for the value. SAP's OData key, so changing it replaces the secure parameter. At most 150 characters.
- `secure_param_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The confidential value, at most 4096 characters. Write-only: Terraform never stores it in plan or state, and SAP never returns it. It is sent on create and on every update, because an update replaces the artifact and the Monitor UI requires re-entering the value on every edit.
- `secure_param_wo_version` (String) An arbitrary marker (for example a counter or a date) that you change whenever secure_param_wo changes. Terraform cannot see the write-only value, so changing this marker is what triggers the update that sends the new value.

### Optional

- `description` (String) A free-text description of the artifact, at most 1024 characters.

### Read-Only

- `deployed_by` (String) User or client that last deployed the artifact.
- `deployed_on` (String) When the artifact was last deployed, RFC 3339 in UTC.
- `status` (String) Deployment status SAP reports, for example "DEPLOYED".

## Import

```shell
terraform import sapintegrationsuite_secure_parameter.custom_adapter_api_key CUSTOM_ADAPTER_API_KEY
```

The ID is the name. Name and description are recovered; the first apply after an import sends
the configured value.

## Limitations

- **SAP:** the API is undocumented. Every write answered `202` without a body on the tenant; the
  provider reads the parameter back afterwards.
- **Provider:** Edge Integration Cell targeting is not offered. Values are limited to 4,096
  characters and names to 150, as the `$metadata` declares.
