# sapintegrationsuite_alternative_partner (Resource)

An alternative partner maps how a partner is identified in incoming messages, as the triple of
agency, scheme and identifier (for example a GLN or a sender interface), to the internal partner
ID (Pid) that its Partner Directory entries are stored under. Integration flows use it to find
the right Pid for an incoming message.

**Status:** supported. Backed by `AlternativePartners` of the Partner Directory API.

## Prerequisites

- An OAuth client with the role `AuthGroup_TenantPartnerDirectoryConfigurator`.
- A partner ID (Pid) chosen by you. It does not have to exist: SAP creates a Pid the first time
  an entry references it, and there is no resource for partners themselves.

## Lifecycle

| Operation | What happens |
|---|---|
| Create | Creates the mapping. SAP's key is the hex encoding of agency, scheme and identifier; the provider computes it. |
| Read | Reads the Pid the identity resolves to. |
| Update | A changed `partner_id` repoints the mapping in place. |
| Replacement | Changing `agency`, `scheme`, `external_id` or `runtime_location_id` creates a new mapping. |
| Delete | Deletes this mapping only. |

## Example Usage

```terraform
resource "sapintegrationsuite_alternative_partner" "sender" {
  agency      = "Sender_1"
  scheme      = "SenderInterface"
  external_id = "Interface_1"
  partner_id  = "CS_Scenario_1"
}
```

## Schema

### Required

- `agency` (String) The external scheme agency identifier, for example "Sender_1".
- `external_id` (String) The external identifier within agency/scheme, for example "Interface_1".
- `partner_id` (String) The internal Partner ID (Pid) this external identity resolves to. Mutable in place: SAP documents PUT for repointing an existing mapping at a different Pid.
- `scheme` (String) The external identification scheme, for example "SenderInterface".

### Optional

- `runtime_location_id` (String) NOT SUPPORTED YET. Edge Integration Cell targeting has not passed its acceptance test on a tenant with an Edge Integration Cell; leave this unset until it has. If set, requests go to /location/<id>/api/v1 on the same tenant host, the service root SAP Help documents for Edge Integration Cells, and the value is the runtime location ID SAP shows in the monitoring URL after selecting the Edge Integration Cell as runtime ({"edge":{"runtimeLocationId":"myedge"}}). Use it only at your own risk. Changing it replaces the resource.

### Read-Only

- `id` (String) Composite identifier in the form "<hex_agency>/<hex_scheme>/<hex_external_id>" (each segment hex-encoded so the identifier is well-formed regardless of what characters agency, scheme, and external_id contain).

## Import

```shell
# The import ID is the three key components hex-encoded and joined by "/":
# hex("Sender_1")/hex("SenderInterface")/hex("Interface_1"). Hex text can
# never itself contain "/", so this is unambiguous regardless of what
# characters agency, scheme, and external_id contain.
terraform import sapintegrationsuite_alternative_partner.sender \
  53656e6465725f31/53656e646572496e74657266616365/496e746572666163655f31
```

The ID is the three key parts hex-encoded and joined with `/`, because the parts themselves
may contain `/`. `printf 'Sender_1' | xxd -p` prints the hex form of one part. Everything is
recovered.

## Limitations

- **SAP:** the key is hex-encoded; the provider hides that except in the import ID.
- **Provider:** Edge Integration Cell targeting through `runtime_location_id` is not supported and has not
  been tested; leave it unset.
