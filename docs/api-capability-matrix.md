# API Capability Matrix

This matrix records what the API research found per object: which operations SAP's public
APIs offer, and the evidence for each. It deliberately has no Terraform status column. The
provider's support status, the contract source of each implemented feature and its known
limitations are generated from `internal/features/catalog.go` into
[`feature-support.md`](feature-support.md), and the dated evidence behind every open item is in
[`research/capability-evidence-2026.md`](research/capability-evidence-2026.md). Keeping the
status in one generated place is what stops the two from contradicting each other.

Scope: SAP Cloud Integration's public "Integration Content", "Security Content", and
"Partner Directory" OData V2 APIs (published under the `CloudIntegrationAPI` package on
SAP Business Accelerator Hub), the Access Policy API, and the other Integration Suite
capabilities listed below. "Not documented; works on a tenant" marks operations that exist in
the service's `$metadata` and were verified on a tenant but that SAP does not document; the
provider treats them as unofficial.
