# sapintegrationsuite_partner_authorized_user (Data Source)

Reads the partner ID an inbound communication user is authorized to act as. Look the user up
in lowercase, the form SAP stores it in.

**Status:** supported.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_partner_authorized_user" "commuser" {
  user = "commuser1"
}
```
