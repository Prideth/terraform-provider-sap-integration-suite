# sapintegrationsuite_partners (Data Source)

Lists every partner ID (Pid), following SAP's paging to the end. This is the starting point for
adopting existing Partner Directory content.

**Status:** read_only.

An empty Partner Directory returns an empty list.

## Example Usage

```terraform
data "sapintegrationsuite_partners" "all" {}

output "known_partner_ids" {
  value = data.sapintegrationsuite_partners.all.pids
}
```
