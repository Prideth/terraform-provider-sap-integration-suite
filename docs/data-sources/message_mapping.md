# sapintegrationsuite_message_mapping (Data Source)

Reads the name and version of a package-level message mapping, for example to deploy a mapping
that is maintained in the UI.

**Status:** supported.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_message_mapping" "customer" {
  package_id = "UTILITIES"
  mapping_id = "customer-mapping"
}

output "customer_message_mapping_version" {
  value = data.sapintegrationsuite_message_mapping.customer.version
}
```
