# sapintegrationsuite_api_providers (Data Source)

Lists every API provider the configured client can see, including connection types the
resource does not manage (on-premise, Open Connectors, Cloud Integration). Needs the `api_management` block in the provider configuration.

**Status:** partial, like the resource.

Returns an empty list when there are none.

## Example Usage

```terraform
data "sapintegrationsuite_api_providers" "all" {}

output "internet_providers" {
  value = [
    for p in data.sapintegrationsuite_api_providers.all.providers :
    p.name if p.dest_type == "INTERNET"
  ]
}
```

### Nested Schema for `providers`

Read-Only:

- `auth_type` (String) Authentication method for the backend, for example "BASIC".
- `description` (String) Free-text description of the provider.

- `host` (String) Backend host, without scheme.
- `name` (String) The API provider's name, its key.
- `path_prefix` (String) Path prefix for SAP Gateway catalog service discovery, if set.
- `port` (Number) Backend port.
- `service_collection_url` (String) Relative path of the SAP Gateway catalog service, if set.
- `title` (String) Display title of the provider.
- `trust_all` (Boolean) Whether API Management accepts any TLS certificate the backend presents.
- `use_ssl` (Boolean) Whether the connection to the backend uses TLS.
- `user_name` (String) User for basic authentication. The password is never returned.
