# sapintegrationsuite_integration_package (Data Source)

Looks up an integration package by its technical ID, for example to attach artifacts to a
package that another team or configuration owns.

**Status:** supported.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_integration_package" "utilities" {
  id = "UTILITIES"
}

output "utilities_package_name" {
  value = data.sapintegrationsuite_integration_package.utilities.name
}
```
