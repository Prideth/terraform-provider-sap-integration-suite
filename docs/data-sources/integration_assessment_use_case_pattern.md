# sapintegrationsuite_integration_assessment_use_case_pattern (Data Source)

Returns the Id, description, example and style of a use case pattern of SAP's Integration Solution
Advisory Methodology. A use case pattern refines an integration style; `style_id` is that style.
The Ids differ between tenants, the names do not.

**Status:** supported. SAP's Entities API specification on the Business Accelerator Hub
documents this entity, and its requests were verified on a tenant. No opt-in switch is needed.

Names are compared exactly, including case. The plan fails when no entry or more than one entry
has the name.

## Example Usage

```terraform
# Needs provider.integration_assessment.
variable "use_case_pattern_name" {
  description = "Name of a use case pattern, as the Integration Assessment UI lists it."
  type        = string
}

data "sapintegrationsuite_integration_assessment_use_case_pattern" "selected" {
  name = var.use_case_pattern_name
}

output "use_case_pattern_style_id" {
  description = "The integration style the pattern refines."
  value       = data.sapintegrationsuite_integration_assessment_use_case_pattern.selected.style_id
}
```

## Use in a technology profile

A use case pattern refines a style, so `style_id` can link your technology to that style:

```terraform
resource "sapintegrationsuite_integration_assessment_technology_style" "acme_esb" {
  technology_id = sapintegrationsuite_integration_assessment_technology.acme_esb.id
  style_id      = data.sapintegrationsuite_integration_assessment_use_case_pattern.selected.style_id
}
```
