# sapintegrationsuite_partner (Data Source)

Confirms that a partner ID (Pid) exists. There is no partner resource: SAP creates a Pid when
the first entry references it, and deleting a partner deletes everything it holds.

**Status:** read_only.

If the Pid is not in the Partner Directory, the plan fails.

## Example Usage

```terraform
data "sapintegrationsuite_partner" "existing" {
  pid = "PartnerZ"
}
```
