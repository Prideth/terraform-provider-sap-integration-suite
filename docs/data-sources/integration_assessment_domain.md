# sapintegrationsuite_integration_assessment_domain (Data Source)

Returns the Id and description of an integration domain of SAP's Integration Solution Advisory
Methodology, to link a technology to it with
[`sapintegrationsuite_integration_assessment_technology_domain`](../resources/integration_assessment_technology_domain.md).
The Ids differ between tenants, the names do not.

**Status:** supported. SAP's Entities API specification on the Business Accelerator Hub
documents this entity, and its requests were verified on a tenant. No opt-in switch is needed.

Names are compared exactly, including case. The plan fails when no entry or more than one entry
has the name.

## Example Usage

```terraform
# Needs provider.integration_assessment.
variable "domain_name" {
  description = "Name of an integration domain, as the Integration Assessment UI lists it."
  type        = string
}

data "sapintegrationsuite_integration_assessment_domain" "selected" {
  name = var.domain_name
}

output "domain_id" {
  value = data.sapintegrationsuite_integration_assessment_domain.selected.id
}
```

## Use in a technology profile

Link your technology to the domain:

```terraform
resource "sapintegrationsuite_integration_assessment_technology_domain" "acme_esb" {
  technology_id = sapintegrationsuite_integration_assessment_technology.acme_esb.id
  domain_id     = data.sapintegrationsuite_integration_assessment_domain.selected.id
}
```
