# sapintegrationsuite_api_key_value_map (Data Source)

Reads a key value map and its entries. Entry values are marked sensitive, because maps can
carry runtime credentials. Needs the `api_management` block in the provider configuration.

**Status:** partial, like the resource.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
# Entry values are marked sensitive in this data source's schema, even
# though only unencrypted maps are supported.
data "sapintegrationsuite_api_key_value_map" "oc_instance_token" {
  name     = "apim.oc.instance.token"
  scope    = "APIPROXY"
  scope_id = "SampleAPI"
}
```
