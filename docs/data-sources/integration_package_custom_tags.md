# sapintegrationsuite_integration_package_custom_tags (Data Source)

Reads the custom tags of one integration package: one entry for every tag of the tenant's custom
tag configuration, with the values the package has for it. A tag the package has no value for is
listed with an empty `values` list. Use it to check that packages are classified, for example in
a `check` block or an output, or to see which tags a package has before managing them with
[`sapintegrationsuite_integration_package_custom_tag`](../resources/integration_package_custom_tag.md).

**Status:** supported. The read (`GET IntegrationPackages('<id>')/CustomTags`) is documented in
SAP's Integration Content API specification.

The values are split the way SAP separates them (at `|`, trimmed), so a tag set in SAP's UI to
`Sales | Transport` reads as `["Sales", "Transport"]`. A package that does not exist fails the
plan with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_integration_package_custom_tags" "orders" {
  package_id = "OrderProcessing"
}

# Tag name -> values, for example to check that every package has an owner.
output "order_package_tags" {
  value = { for t in data.sapintegrationsuite_integration_package_custom_tags.orders.tags : t.name => t.values }
}
```
