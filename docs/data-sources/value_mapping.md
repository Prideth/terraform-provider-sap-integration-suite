# sapintegrationsuite_value_mapping (Data Source)

Reads the name and version of a value mapping, for example to deploy a value mapping that is
maintained in the UI with [`sapintegrationsuite_value_mapping_deployment`](../resources/value_mapping_deployment.md).
The mapping entries themselves are not returned.

**Status:** partial, like the value mapping resource.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_value_mapping" "company_codes" {
  package_id = "UTILITIES"
  mapping_id = "company-codes"
}

output "company_codes_value_mapping_version" {
  value = data.sapintegrationsuite_value_mapping.company_codes.version
}
```
