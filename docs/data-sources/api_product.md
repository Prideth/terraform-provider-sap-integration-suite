# sapintegrationsuite_api_product (Data Source)

Reads an API product and the names of the proxies it bundles. Needs the `api_management` block in the provider configuration.

**Status:** supported.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_api_product" "sample" {
  name = "SampleProduct"
}

output "sample_product_proxies" {
  value = data.sapintegrationsuite_api_product.sample.api_proxy_names
}
```
