# sapintegrationsuite_integration_adapter (Data Source)

Reads a custom adapter, including the `package_id` that an import of
[`sapintegrationsuite_integration_adapter`](../resources/integration_adapter.md) needs. Useful
before adopting an adapter, or to deploy one that this configuration does not own.

**Status:** partial, like the adapter resource.

If the object does not exist, the plan fails with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_integration_adapter" "sftp_extension" {
  id = "custom-sftp-extension"
}
```
