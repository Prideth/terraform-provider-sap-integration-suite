# sapintegrationsuite_integration_assessment_style (Data Source)

Returns the Id and description of an integration style of SAP's Integration Solution Advisory
Methodology, to link a technology to it with
[`sapintegrationsuite_integration_assessment_technology_style`](../resources/integration_assessment_technology_style.md).
The Ids differ between tenants, the names do not.

**Status:** supported. SAP's Entities API specification on the Business Accelerator Hub
documents this entity, and its requests were verified on a tenant. No opt-in switch is needed.

Names are compared exactly, including case. The plan fails when no entry or more than one entry
has the name.

## Example Usage

```terraform
# Needs provider.integration_assessment.
variable "style_name" {
  description = "Name of an integration style, as the Integration Assessment UI lists it."
  type        = string
}

data "sapintegrationsuite_integration_assessment_style" "selected" {
  name = var.style_name
}

output "style_id" {
  value = data.sapintegrationsuite_integration_assessment_style.selected.id
}
```

## Use in a technology profile

Link your technology to the style:

```terraform
resource "sapintegrationsuite_integration_assessment_technology_style" "acme_esb" {
  technology_id = sapintegrationsuite_integration_assessment_technology.acme_esb.id
  style_id      = data.sapintegrationsuite_integration_assessment_style.selected.id
}
```
