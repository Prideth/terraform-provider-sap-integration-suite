# sapintegrationsuite_value_mapping_entries (Data Source)

Reads the entries of one agency pair of a value mapping: each source and target value pair, the
ID SAP gives it, and whether SAP uses it by default for its source value. Use it to look up a
mapping in a configuration, or to find the ID for importing a
[`sapintegrationsuite_value_mapping_entry`](../resources/value_mapping_entry.md).

**Status:** partial, like the entry resource. The reads (`ValMapSchema(...)/ValMaps` and
`DefaultValMaps`) are documented in SAP's Integration Content API specification and passed the
entry resource's acceptance test on a tenant.

Reading the agency pair the other way round (target as source) returns the same entries with
source and target values swapped. An agency pair the value mapping does not have fails the plan
with SAP's `404`.

## Example Usage

```terraform
data "sapintegrationsuite_value_mapping_entries" "countries" {
  value_mapping_id  = "CountryCodes"
  source_agency     = "ERP"
  source_identifier = "Country"
  target_agency     = "CRM"
  target_identifier = "CountryCode"
}

# The target values of every source value.
output "country_codes" {
  value = {
    for e in data.sapintegrationsuite_value_mapping_entries.countries.entries :
    e.source_value => e.target_value...
  }
}
```
