# sapintegrationsuite_integration_assessment_key_characteristic_group (Data Source)

Returns the Id and description of a key characteristic group of SAP's Integration Solution Advisory
Methodology. Groups structure the key characteristics that technologies are rated on. The group
is informational: a rating links to a key characteristic value, not to a group.

**Status:** supported. SAP's Entities API specification on the Business Accelerator Hub
documents this entity, and its requests were verified on a tenant. No opt-in switch is needed.

Names are compared exactly, including case. The plan fails when no entry or more than one entry
has the name.

## Example Usage

```terraform
# Needs provider.integration_assessment.
variable "key_characteristic_group_name" {
  description = "Name of a key characteristic group, as the Integration Assessment UI lists it."
  type        = string
}

data "sapintegrationsuite_integration_assessment_key_characteristic_group" "selected" {
  name = var.key_characteristic_group_name
}

output "key_characteristic_group_id" {
  value = data.sapintegrationsuite_integration_assessment_key_characteristic_group.selected.id
}
```
