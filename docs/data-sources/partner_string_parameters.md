# sapintegrationsuite_partner_string_parameters (Data Source)

Lists every string parameter of one partner ID, following SAP's paging to the end, for example
before importing them as resources.

**Status:** supported.

A partner without string parameters returns an empty list.

## Example Usage

```terraform
data "sapintegrationsuite_partner_string_parameters" "all" {
  partner_id = "PartnerZ"
}

output "partner_string_parameter_ids" {
  value = [for v in data.sapintegrationsuite_partner_string_parameters.all.values : v.parameter_id]
}
```
