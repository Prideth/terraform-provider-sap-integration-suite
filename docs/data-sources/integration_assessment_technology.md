# sapintegrationsuite_integration_assessment_technology (Data Source)

Returns the Id of a technology, typically one that SAP delivers, so that technology instances
can be created for it.

**Status:** supported. SAP's Entities API specification on the Business Accelerator Hub
documents this entity, and its requests were verified on a tenant. No opt-in switch is needed.

Names are compared exactly, including case. The plan fails when no entry or more than one entry
has the name.

## Example Usage

```terraform
# Needs provider.integration_assessment.
variable "technology_name" {
  description = "Exact name of one of the technologies the tenant lists."
  type        = string
}

data "sapintegrationsuite_integration_assessment_technology" "selected" {
  name = var.technology_name
}

resource "sapintegrationsuite_integration_assessment_technology_instance" "prd" {
  name                = "Integration technology PRD"
  technology_id       = data.sapintegrationsuite_integration_assessment_technology.selected.id
  deployment_model_id = data.sapintegrationsuite_integration_assessment_deployment_model.selected.id
}
```
